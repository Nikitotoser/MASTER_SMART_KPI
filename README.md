SmartEnergy Lab: Комплексна IoT-система моніторингу та ML-прогнозування енергоспоживання

Виконав: студент магістратури Гончаренко Микита

📌 Анотація проєкту

SmartEnergy Lab — це апаратно-програмний комплекс, призначений для збору, збереження, аналізу та прогнозування показників енергоспоживання в режимі реального часу. Система побудована на мікросервісній архітектурі, що об'єднує фізичні пристрої (Edge IoT), хмарні брокери повідомлень, бази даних часових рядів та алгоритми машинного навчання.

⚠️ ВАЖЛИВА ПРИМІТКА ЩОДО РОБОТИ СИСТЕМИ:
Програмна інфраструктура (бекенди, база даних, фронтенд) розгортається локально і працює автономно. Проте система не відображатиме актуальну телеметрію без увімкненої фізичної плати ESP32. Мікроконтролер є єдиним джерелом генерації реальних даних з датчиків. Без його роботи графіки на дашборді не будуть оновлюватися.

🏗 Архітектура та компоненти системи

Проєкт складається з 4 незалежних модулів, кожен з яких виконує свою ізольовану функцію:

1. esp32_gateway (Апаратний Edge-шлюз)

Опис: Фізичний мікроконтролер ESP32, написаний на C++ (PlatformIO).

Функціонал: Опитує підключені датчики струму/напруги (INA226) та Modbus-пристрої.

Мережа: Підключається до Wi-Fi та публікує зібрані метрики у хмарний MQTT-брокер (broker.hivemq.com) за допомогою бібліотеки PubSubClient.

2. python_backend (IoT Data Ingestion API)

Опис: Мікросервіс на базі FastAPI.

Функціонал: Працює як MQTT-підписник. Асинхронно отримує "сирі" пакети даних від ESP32, проводить валідацію, структурує їх та виконує пакетний запис (batch writing) до бази даних InfluxDB.

3. smart_energy_edge (ML Prediction Engine)

Опис: Аналітичний мікросервіс на базі Python (FastAPI + LightGBM + Pandas).

Функціонал: Відповідає за обробку історичних даних та генерацію прогнозів. Завантажує попередньо навчену модель градієнтного бустингу, збагачує дані телеметрії зовнішніми погодними факторами та видає прогнози навантаження через REST API.

4. react-frontend (Web Dashboard)

Опис: Клієнтський інтерфейс розроблений на React.js з використанням збирача Vite.

Функціонал: Забезпечує інтерактивну візуалізацію. Відправляє HTTP-запити до бекенд-сервісів для отримання історичної статистики та ML-прогнозів, після чого будує динамічні графіки.

🚀 Технологічний стек

Embedded: C++, PlatformIO, ESP32, PubSubClient

Backend: Python 3.11, FastAPI, Pydantic, Uvicorn

Data Science / ML: LightGBM, Pandas, Scikit-learn, PySpark

Frontend: React, JavaScript, Vite, CSS

Інфраструктура: Docker, Docker Compose, InfluxDB 2.x, MQTT

⚙️ Інструкція з розгортання та запуску

Частина 1: Запуск програмної інфраструктури (Серверна частина)

Всі мікросервіси та база даних контейнеризовані. Для їх запуску потрібен встановлений Docker та Docker Compose.

Відкрийте термінал у кореневій папці проєкту.

Виконайте команду для збірки та запуску контейнерів у фоновому режимі:

docker-compose up --build -d


Перевірте статус контейнерів:

docker-compose ps


Фронтенд-дашборд буде доступний у браузері за адресою: http://localhost:5173 (або http://localhost:3000 залежно від конфігурації).

Частина 2: Запуск апаратної частини (ESP32)

Відкрийте папку esp32_gateway у VS Code із встановленим розширенням PlatformIO.

Підключіть плату ESP32 до комп'ютера через USB-кабель.

Виконайте збірку коду (кнопка Build / ✓ у нижній панелі).

Завантажте прошивку на плату (кнопка Upload / → у нижній панелі).

Відкрийте монітор порту (кнопка Monitor), щоб переконатися, що плата успішно підключилася до Wi-Fi та почала передачу пакетів у MQTT.

🧪 Запуск автоматизованих тестів

У проєкті налаштовано unit-тестування для Python-бекендів за допомогою фреймворку pytest.

Для запуску тестів сервісу python_backend:

cd python_backend
python -m venv venv
source venv/Scripts/activate  # (для Windows: venv\Scripts\activate)
pip install -r requirements.txt
pytest tests/


Для запуску тестів ML-модуля smart_energy_edge:

cd smart_energy_edge
python -m venv venv
source venv/Scripts/activate  # (для Windows: venv\Scripts\activate)
pip install -r requirements.txt
pytest tests/
