# Smart Energy IoT Platform

**Крок 1. Запуск інфраструктури**
1. Відкрийте термінал у кореневій папці проєкту `MASTER_SMART_ENERGY`.
2. Виконайте команду для збірки та запуску всіх контейнерів:
   `docker-compose up -d --build`
3. Дочекайтеся завершення запуску.

**Крок 2. Перегляд дашборду**
Відкрийте браузер та перейдіть за адресою: http://localhost:5173

**Крок 3. Запуск автоматизованих тестів**
Не зупиняючи контейнери, відкрийте нове вікно терміналу та по черзі виконайте наступні команди для перевірки працездатності системи:

1. Перевірка серверної частини (API):
   `docker exec -it smart_energy_api pytest tests/test_api.py -v`

2. Перевірка алгоритмів прогнозування (MLOps):
   `docker exec -it smart_energy_ml_api python -m pytest -v`
